# Smart Bus Ticket Booking & Reservation System

A Python 3 console application for a small bus service, built strictly in accordance with the Product Requirements Document (PRD).

---

## 1. Project Purpose & Vision
The system manages bus routes, ticket reservations, booking cancellations, seat availability, departure schedules, and financial/occupancy reporting using core Python data structures and control flow.

---

## 2. Requirements & Setup
- **Language**: Python 3.7+
- **External Dependencies**: None (uses standard Python library only)
